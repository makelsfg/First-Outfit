# STORY.md · 小白穿衣推荐项目汇报

## 主题与受众
- 主题：微信小程序「First-Outfit · 小白穿衣推荐」项目汇报
- 受众：同学与老师（课堂汇报）
- 目标：讲清「真实痛点 → 产品方案 → 技术实现（含 S.C.A.F.F. 分析）→ 收获展望」的完整逻辑链
- 基调：真诚、极简、有温度；强调"确定性规则 + AI 兜底"的工程思维

## 页面叙事（9 页）

| # | 角色 | 页面 | 叙事任务 |
|---|---|---|---|
| 01 | hero | 封面 | 项目名 + 一句话定位「告诉你今天穿什么，不会出错」 |
| 02 | supporting | 为什么做 | 痛点：刚上大学不懂穿衣——穿多热/穿少冷/面试怕随意/上课怕奇怪；不是不想学，是没人教 |
| 03 | supporting | 做了什么 | 三大 tab 功能总览（今日推荐/我的衣橱/设置 + 客服问答），配 3 张真实运行截图 |
| 04 | supporting | 亮点1·确定性规则引擎 | 温度带 × 场合 × 性别 → 3 套方案；穿什么由规则决定，不让 AI 替用户决定；每套附"为什么" |
| 05 | supporting | 亮点2·真流式问答 | callFunction 拿不到流式响应 → 云函数写库 + db.watch() 曲线实现；全链路降级不炸 |
| 06 | hero | S.C.A.F.F. 项目分析 | 五个维度色块卡：Situation / Challenge / Audience / Format / Foundations |
| 07 | supporting | 技术底座 | 分层架构图：小程序端 → 云函数(getWeather/askLLM) → 高德/百炼/云数据库；密钥全在服务端 |
| 08 | supporting | 收获与展望 | 收获：降级设计、混合架构、为真实用户做减法；展望：打卡/风采库/反馈入口待接入 |
| 09 | hero | 结尾 | 金句「它不教你变时尚，只告诉你今天穿什么，不会出错」+ 致谢 |

## 讲述要点
- 第 2 页用第一人称经历开场，建立共鸣
- 第 4-5 页是技术深度页：先讲问题约束，再讲取舍方案
- 第 6 页 S.C.A.F.F. 是必须完整呈现的核心分析环节，五卡等高排列
- 第 8 页承认未完成功能（打卡/风采库），体现工程诚实
