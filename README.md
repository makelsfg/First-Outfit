# First-Outfit · 小白穿衣推荐

> 给曾经和我一样，不知道穿什么才不出错的你。

## 这是什么

一个面向**穿衣小白**的微信小程序。

如果你刚上大学，因为家庭或成长环境的原因，没有接触过基础的穿衣知识，不知道什么天气穿什么、什么场合穿什么才不出错——这个小程序就是为你做的。

它不教你变时尚，不让你录入衣橱，不让你拍照识衣。它只做一件事：

**告诉你今天穿什么，不会出错。**

## 为什么做这个

我大一的时候，也不知道怎么穿衣搭配。

不是不想学，是没有人教，也不好意思问。穿多了热，穿少了冷，去面试怕穿得太随意，去上课又怕穿得太奇怪。衣柜里衣服不少，但总觉得没衣服穿。

后来慢慢试、慢慢看，才明白穿衣搭配没有想象中那么难。它不需要天赋，只需要有人告诉你几条最基础的规则。

所以我想做一个工具，帮助像曾经的我一样的人。

## 核心功能

### 1. 今日推荐（首页）

打开就能看到：

* 所在城市的**真实天气**、温度、体感温度、季节
* 一套具体的穿搭方案：上衣、内搭、裤子、鞋子
* 一句“为什么这样穿”的解释
* 特殊天气提醒（下雨带伞、大风穿挡风外套、降温加衣服）

不用登录，不用填信息，不用学怎么用。点开，10 秒拿到答案，关掉。

### 2. 每日穿搭打卡

* 首页点击「记录今日穿搭」，拍照或从相册选图完成打卡
* 打卡成功后触发**双重弹窗**：先弹出上传成功提示（1.5 秒后缓缓淡出），紧接着弹出随机鼓励语（放大动画，点击「确定」关闭）
* 当日打卡后按钮变为「今日已打卡」并禁用，次日恢复可打卡

### 3. 个人每日风采库

* 以**瀑布流照片墙**展示历史打卡的照片、日期、当天天气与穿搭摘要
* 支持**管理批量删除**：点「管理」→ 勾选不要的照片 → 点「删除」→ 二次确认（照片不可复原）

### 4. 搜索（接大模型）

搜索框默认填写：

> 这个季节穿啥衣服

用户搜索后，由大模型返回温和、具体、不评判的回答。

提示词面向的用户画像是：

> 刚高考完，因为家庭和环境的原因，没有基本穿衣常识的年轻人。

回答会引导用户一步步学会穿衣搭配，而不是只给一个结果。

搜索历史会保存在本地（最近 20 条），点击可展开查看当时的完整回答，也可一键清空。

### 5. 我的（个人信息）

* 个人信息：昵称、年龄、性别，提供**查看 / 编辑两种模式**，编辑后保存到本地
* 「个人每日风采库」入口，右侧显示「已打卡 X 天」（累计天数）
* 底部有一句鼓励的话：

> 穿衣搭配没有想象中那么难。我曾经也不会，但慢慢就学会了。

还有一个反馈按钮，用户点完可以留下意见。

## 设计原则

* **不评判**：不问“你怎么连这个都不知道”，而是说“很多人一开始都不懂，这很正常”。
* **给兜底**：不确定的时候，永远有一个最简单的安全方案。
* **解释为什么**：不只给结果，还要告诉用户“为什么这样穿不会错”。
* **极简**：不搞衣橱管理，不搞 AI 生成穿搭，不搞社交。打开即用，用完即走。

## 技术栈

* 微信小程序原生开发 + TypeScript
* 微信开发者工具
* 天气 API：高德开放平台（定位逆地理编码 + 实时天气）
* 大模型 API：阿里云百炼 DashScope（OpenAI 兼容接口，模型 `deepseek-v4.1-flash`）
* 数据存储：本地存储（`wx.setStorageSync` / `wx.saveFile`）
* Git / GitHub 版本管理

### 前后端划分

| 层 | 位置 | 职责 | 现状 |
|---|---|---|---|
| **前端** | `miniprogram/` | 页面渲染、穿搭规则引擎、数据与服务封装 | 已完成 |
| **后端** | 暂无独立目录 | 数据持久化、密钥保护、跨设备同步 | 打卡/搜索/个人信息存**本地**；天气与大模型由前端直连第三方 API |

> 说明：出于「先本地跑通、暂不上云」的策略，当前**未拆分出独立后端服务**。`utils/` 下的数据服务（`weather.ts` / `llm.ts` / `checkin.ts`）已做接口抽象，后续接入微信云开发时，只需替换其内部实现为云函数调用，页面代码无需改动。

## 运行说明

1. 从浏览器下载并安装「微信开发者工具」：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开微信开发者工具，点「导入项目」，目录选择项目根目录 `项目-小白穿衣推荐`（即含 `project.config.json` 的那一层）
3. 右上角「详情」→「本地设置」→ 勾选「**不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**」（否则无法请求天气与大模型接口）
4. 在 `miniprogram/utils/config.ts` 中配置 API key：
   - `AMAP_KEY`：高德开放平台「Web服务」类型的 key
   - `DASHSCOPE_KEY`：阿里云百炼 DashScope 的 API Key
5. 编译运行

## 已知限制

* 打卡数据与照片存**本地**，清除缓存或更换设备后会丢失（后续可升级为云开发保存）
* API key 目前**明文写在前端** `config.ts` 中，仅用于开发调试；正式上线前需迁移到后端（如云函数）隐藏，并重新生成 key
