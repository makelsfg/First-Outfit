# First-Outfit · 小白穿衣推荐

> 给曾经和我一样，不知道穿什么才不出错的你。

## 这是什么

一个面向**穿衣小白**的微信小程序。

如果你刚上大学，因为家庭或成长环境的原因，没有接触过基础的穿衣知识，不知道什么天气穿什么、什么场合穿什么才不出错——这个小程序就是为你做的。

它不教你变时尚，不让你录入衣橱，不让你拍照识衣。它只做一件事：

**告诉你今天穿什么，不会出错。**

## 为什么做这个

我大一的时候，也不知道怎么穿衣搭配。

不是不想学，是没有人教，也不好意思问。穿多了热，穿少了冷，去面试怕穿得太随意，去上课又怕穿得太奇怪。衣柜里衣服不少，但总觉得没衣服穿。

后来慢慢试、慢慢看，才明白穿衣搭配没有想象中那么难。它不需要天赋，只需要有人告诉你几条最基础的规则。

所以我想做一个工具，帮助像曾经的我一样的人。

## 核心功能

### 1\. 穿衣推荐（首页）

打开就能看到：

* 今天的天气、温度、季节
* 一套具体的穿搭方案：上衣、裤子、鞋子
* 一句“为什么这样穿”的解释
* 特殊天气提醒（下雨带伞、大风穿挡风外套、降温加衣服）

不用登录，不用填信息，不用学怎么用。点开，10 秒拿到答案，关掉。

### 2\. 搜索（接大模型）

搜索框默认填写：

> 这个季节穿啥衣服

用户搜索后，由大模型返回温和、具体、不评判的回答。

提示词面向的用户画像是：

> 刚高考完，因为家庭和环境的原因，没有基本穿衣常识的年轻人。

回答会引导用户一步步学会穿衣搭配，而不是只给一个结果。

### 3\. 个人信息

* 修改昵称
* 年龄
* 性别

底部有一句鼓励的话，大意是：

> 穿衣搭配没有想象中那么难。我曾经也不会，但慢慢就学会了。

还有一个反馈按钮，用户点完可以留下意见。

## 设计原则

* **不评判**：不问“你怎么连这个都不知道”，而是说“很多人一开始都不懂，这很正常”。
* **给兜底**：不确定的时候，永远有一个最简单的安全方案。
* **解释为什么**：不只给结果，还要告诉用户“为什么这样穿不会错”。
* **极简**：不搞衣橱管理，不搞 AI 生成穿搭，不搞社交。打开即用，用完即走。

## 技术栈

* 微信小程序原生开发
* 微信开发者工具
* 天气 API（和风天气 / 高德开放平台）
* 大模型 API（用于搜索页问答）
* Git / GitHub 版本管理
